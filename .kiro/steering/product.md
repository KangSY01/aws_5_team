# 제품 개요

## 과제 필수 요구사항
공식 과제에 명시된 요구사항을 기록한 것입니다. 우선순위 결정이 아닙니다.

- 다국어(영·중·일) 자연어 및 음성 질의응답
- 선호·체류 기간·위치 기반 맞춤형 여행 코스 자동 추천
- 대중교통·축제·행사·맛집 실시간 정보 연동 안내
- 이미지 인식 기반 안내(간판·메뉴판 번역, 관광지 설명)
- 긴급 상황(의료·분실 등) 대응 안내 및 관련 기관 연계

## 정의
부산을 찾은 외국인 관광객(영어·일본어·중국어 간체·번체)에게 프로필 맞춤 일정을 지도 위에 생성하는 생성형 AI 안내 에이전트입니다.
혼잡·비·휴무·빠듯한 이동 같은 문제를 먼저 검출해 알리고, 일정을 최대한 유지하면서 문제 구간만 수정합니다.

- 대회: AWS AI 마에스트로 해커톤 (부산시 지역 현안)
- 공식 주제: 생성형 AI 기반 외국인 관광객 다국어 맞춤형 안내 Agent
- 핵심 기능 이름: **Schedule Guardian** (서비스 전체 이름이 아닌 핵심 기능 이름)

## 차별점
다른 AI 일정 서비스는 문제가 생기면 일정 전체를 다시 생성합니다.
이 서비스는 사용자가 고른 일정을 최대한 유지하고 문제 구간만 수정합니다.

## 기능 우선순위
원본은 노션 「역할 분담과 타임테이블」입니다. **1~5순위는 모두 필수**이고 토 00:00 기능 동결 전까지 모두 완성합니다. 6순위만 선택입니다.
1·2순위를 먼저 끝내고(금 18:00 점검 2), 3·4·5순위는 금요일 저녁에 4명이 나눠서 동시에 진행합니다.

1. 핵심: 프로필 입력(언어·관심사·동행·식단·예산) · 일정 생성(3~5곳) · 지도 경로 표시
2. 차별점: Schedule Guardian. 규칙 점검 → 카드 배지 알림 → 변경이 작은 해결책부터 제시 + 보전 지표 · 채팅으로도 수정
3. 주요 기능: 대중교통·축제·행사·맛집 정보 안내 · 채팅 음성 입력(Transcribe) · 여행 중 음성 출력(Polly)
4. 부산 현안: 행사 레이어 · 행사일 혼잡 가중 규칙 · 대형 행사 관람지·귀가 분산
5. 외국인 편의: 이미지 인식(메뉴판·간판, Textract) · 현지인에게 보여주기 카드(Polly 한국어 음성) · 장소 후속 질문
6. 선택(시간 남으면): 긴급 상황 안내 · 일몰 타이밍 · 무장애 프로필 · 도움 요청 버튼 · 일정 3개 병렬 생성

우선순위가 낮은 기능을 구현하면서 높은 기능의 동작을 손상하지 마십시오.

## 화면 모드
- 계획 모드: 지도 + 아래 시트, 책갈피 탭(Plan / Chat), 하단 고정 입력바
- 여행 중 모드: 다음 목적지 카드(열차 시각표 기준) · 현지인에게 보여주기 카드 · 늦었어요 / 붐벼요 / 도움 버튼
- 화면의 기준은 계획이고, 채팅은 계획을 수정하는 입력 수단입니다.

## 데모 시나리오 요약
구현이 아래 흐름을 손상하지 않게 하십시오.
일본인 커플, 11/28(토) 해운대 빛축제 개막일 기준입니다. 시각은 `DEMO_NOW`, 날씨·혼잡은 `USE_MOCK=1`의 샘플 데이터로 재현합니다.

지금 뼈대의 샘플(`backend/app/data/`)은 11/21(토) 일정 4곳이고, 빛축제 장소·행사 데이터는 아직 없습니다. 아래 장면에 필요한 데이터·API(행사, 사진 번역, 음성)는 계약 변경 PR로 추가합니다.

1. 일본어 한 문장 입력 → 일정 생성 → 해운대 카드에 혼잡 배지 자동 표시, 빛축제 18:00 일정 자동 🔒 고정
2. 배지 선택 → 대안 미리보기(변경 1곳 · 4곳 유지 · 이동 +N분) → 바꾸기 / 되돌리기
3. 메뉴판 사진 → 사진 위 일본어 번역 · 매운 메뉴 표시
4. 현지인에게 보여주기 카드 + 한국어 음성
5. 13~15시 비 주입 → 시간만 이동해 해결("변경 0곳")
6. "30분 늦었어요" → 고정 일정 유지하며 재조정
7. 축제 후 귀가 혼잡 → 한 정거장 도보 이동 / 30분 휴식 후 출발
